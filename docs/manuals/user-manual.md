# User Manual

This manual is the primary entry point for using the bot and master runtime day to day.

## Core Workflows

- Single bot mode: start the bot, attach a Codex session, and interact from allowlisted Slack channels.
- Master mode: load an agent, start it, and prompt from the mapped Slack or Discord channel.
- Follow-up routing: continue the conversation in the same Slack thread or Discord thread.
