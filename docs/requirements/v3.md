Future:

- Master intelligent


## Glossary

- **staff agent**: the LLM agent that do the workload
- **staff**: the subagent in LLM agent
- **master**: the controller, orchestrator
- **user**: the user who use this system
- **topic**: a subject to discuss and work with, in a form of a chat thread, like a discord thread. staff agents allocate separate sessions for each topics

## Model

### Datamodel
- Workspace:
	- repo
	- project metadata
	- list of **topics**
	- staff agent container registry
	- Memory(future)
- Topic
	- subject
	- chat history
	- Memory(future)
- Chat
	- message
	- attachments
	- mentions
	- transcripts(message from staff agent)


### Container structure
- **CI/CD container**: manage lifecycle of master container
- **Master container**:
	- Runs Frontend
	- Manage workspace Registry
		- workspace
			- Topics
				- worktree
				- agent session
			- agents
			- agent containers
	- Manage staff agent container lifecycle
- **Agent containers**:
	- agent runtime, runs multiple agent sessions
	- mount worktree volumes

## User stories

### Daily workflow

- User create a workspace in Frontend, providing:
	- Github repo
- Master create main workspace volume
	- checkout the repo to that volume
	- populate agent environment: `~/.claude` & `~/codex`
	- Master register the workspace meta:
		- LLM agent config
		- LLM subagents
		- customized staff agent runtime image
- Master create staff agent container of the workspace
- staff agent container mount the workspace volume
- User start a topic in the Frontend
- Master create:
	- feature branch
	- corresponding worktree on master workspace
	- LLM agent session
- User mentions one of the subagents of the workspace to start work on the topic chat, frontend should have subagent suggestion for user to select
- Master route the prompt to staff agent container using json mode, specifying:
	- LLM agent (`codex` or `claude code`)
	- subagent
	- worktree
	- session id of LLM agent session
- Master provide "thinking" feedback
- staff agent replies with json format, master show the last response on the chat, with folded detail response
- User can mention other subagent when one is processing
- User can attach images and docx documents when mentioning staff agent
